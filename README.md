# ⚖️ SpecterSummarizer: Legal Judgment Summarization

A T5-based model for summarizing legal judgments, fine-tuned on legal documents to generate concise and accurate abstractive summaries.

## 📜 Overview

SpecterSummarizer leverages the T5 (Text-to-Text Transfer Transformer) architecture to perform abstractive summarization of legal judgments. Unlike extractive summarization, this model generates new sentences to capture the essence of complex legal documents, making it ideal for processing lengthy court judgments.

**Key Features:**
- **T5-based Architecture**: Uses the powerful T5 model for high-quality abstractive summarization
- **Automated Pipeline**: Complete Windows batch script for end-to-end execution
- **GPU Optimized**: Designed for NVIDIA GPUs with 6GB VRAM using mixed precision (FP16) and gradient checkpointing
- **Hyperparameter Tuning**: Integrated Optuna-based tuning for optimal model performance
- **Comprehensive Workflow**: Includes preprocessing, training, validation, and evaluation scripts

## 🚀 Getting Started

### Prerequisites

- **Python**: Version 3.7 or higher
- **GPU**: NVIDIA GPU with CUDA support (minimum 6GB VRAM)
- **Operating System**: Windows (for batch script) or macOS/Linux (manual execution)

### Installation

1. **Clone the repository:**

```bash
git clone https://github.com/abhaypatil-code/SpecterSummarizer.git
cd SpecterSummarizer
```

2. **Create and activate a virtual environment:**

**Windows:**
```bash

```

**macOS/Linux:**
```bash
python -m venv venv_legal
source venv_legal/bin/activate
```

3. **Install dependencies:**

```bash
pip install -r requirements.txt
```

4. **Verify GPU availability:**

```python
python -c "import torch; print('CUDA Available:', torch.cuda.is_available())"
```

## 💻 Usage

### Method 1: Automated Pipeline (Windows)

The fastest way to run the complete workflow using the provided batch script.

#### Step 1: Prepare Your Data

Place your dataset files in the `data/` directory:
- `data/train_judg.jsonl` - Legal judgment texts
- `data/train_ref_summ.jsonl` - Reference summaries

#### Step 2: Run the Pipeline

```bash
.\run_pipeline.bat
```

This automatically executes:
1. Creates `outputs/` and `results/` directories
2. Runs `preprocess.py` to split data (80% train, 10% validation, 10% test)
3. Runs `tune.py` for hyperparameter optimization
4. Runs `train.py` to train the model
5. Runs `validate.py` on validation set
6. Runs `run_evaluation.py` on test set for final predictions

#### Pipeline Options

**Skip hyperparameter tuning** (uses existing `hyperparams.json`):
```bash
.\run_pipeline.bat --skip-tuning
```

**Skip training** (uses existing model in `outputs/t5_summarizer`):
```bash
.\run_pipeline.bat --skip-training
```

**Combine flags:**
```bash
.\run_pipeline.bat --skip-tuning --skip-training
```

### Method 2: Manual Step-by-Step Execution

For more control or non-Windows environments.

#### Step 1: Create Directory Structure

```bash
mkdir data outputs results
```

#### Step 2: Add Your Data

Place `train_judg.jsonl` and `train_ref_summ.jsonl` in the `data/` directory.

#### Step 3: Preprocess Data

Split your dataset into train/validation/test sets (80/10/10):

**Windows:**
```bash
python preprocess.py ^
    --judg_path data/train_judg.jsonl ^
    --summ_path data/train_ref_summ.jsonl ^
    --output_dir data ^
    --random_seed 42
```

**macOS/Linux:**
```bash
python preprocess.py \
    --judg_path data/train_judg.jsonl \
    --summ_path data/train_ref_summ.jsonl \
    --output_dir data \
    --random_seed 42
```

**Output:** Creates `train_processed.jsonl`, `val_processed.jsonl`, and `test_processed.jsonl`

#### Step 4: Tune Hyperparameters (Optional but Recommended)

Find optimal hyperparameters using Optuna:

**Windows:**
```bash
python tune.py ^
    --train_file data/train_processed.jsonl ^
    --val_file data/val_processed.jsonl ^
    --output_dir outputs/tuning ^
    --n_trials 20 ^
    --random_seed 42
```

**macOS/Linux:**
```bash
python tune.py \
    --train_file data/train_processed.jsonl \
    --val_file data/val_processed.jsonl \
    --output_dir outputs/tuning \
    --n_trials 20 \
    --random_seed 42
```

**Output:** Saves best hyperparameters to `outputs/tuning/hyperparams.json`

> **Note:** Copy `outputs/tuning/hyperparams.json` to the root directory as `hyperparams.json`, or pass parameters explicitly in the next step.

#### Step 5: Train the Model

Train the T5 model with your data:

**Windows:**
```bash
python train.py ^
    --train_file data/train_processed.jsonl ^
    --val_file data/val_processed.jsonl ^
    --output_dir outputs/t5_summarizer ^
    --learning_rate 3e-5 ^
    --batch_size 4 ^
    --num_epochs 3 ^
    --weight_decay 0.01 ^
    --warmup_steps 500 ^
    --gradient_accumulation_steps 4 ^
    --fp16
```

**macOS/Linux:**
```bash
python train.py \
    --train_file data/train_processed.jsonl \
    --val_file data/val_processed.jsonl \
    --output_dir outputs/t5_summarizer \
    --learning_rate 3e-5 \
    --batch_size 4 \
    --num_epochs 3 \
    --weight_decay 0.01 \
    --warmup_steps 500 \
    --gradient_accumulation_steps 4 \
    --fp16
```

**Output:** Trained model saved to `outputs/t5_summarizer/`

#### Step 6: Validate Model

Generate sample predictions for qualitative review:

**Windows:**
```bash
python validate.py ^
    --model_path outputs/t5_summarizer ^
    --validation_file data/val_processed.jsonl ^
    --batch_size 4 ^
    --results_file results/validation_results.json
```

**macOS/Linux:**
```bash
python validate.py \
    --model_path outputs/t5_summarizer \
    --validation_file data/val_processed.jsonl \
    --batch_size 4 \
    --results_file results/validation_results.json
```

**Output:** Saves validation examples to `results/validation_results.json`

#### Step 7: Evaluate on Test Set

Generate final summaries for the test set:

**Windows:**
```bash
python run_evaluation.py ^
    --model_path outputs/t5_summarizer ^
    --input_file data/test_processed.jsonl ^
    --output_file results/test_predictions.jsonl ^
    --batch_size 4
```

**macOS/Linux:**
```bash
python run_evaluation.py \
    --model_path outputs/t5_summarizer \
    --input_file data/test_processed.jsonl \
    --output_file results/test_predictions.jsonl \
    --batch_size 4
```

**Output:** Predictions saved to `results/test_predictions.jsonl`

## 🤖 Inference on New Data

To generate summaries for new, unseen legal judgments:

### Step 1: Format Your Input

Your input JSONL file must have a `"judgment_text"` field with text prefixed by `"summarize: "`.

**Example format:**
```json
{"judgment_text": "summarize: [Your legal judgment text here]"}
```

You can create a script to convert your raw data to this format (similar to the example `convert_input.py` mentioned in the project).

### Step 2: Run Inference

**Windows:**
```bash
python run_evaluation.py ^
    --model_path outputs/t5_summarizer ^
    --input_file data/your_input.jsonl ^
    --output_file results/your_predictions.jsonl ^
    --batch_size 4
```

**macOS/Linux:**
```bash
python run_evaluation.py \
    --model_path outputs/t5_summarizer \
    --input_file data/your_input.jsonl \
    --output_file results/your_predictions.jsonl \
    --batch_size 4
```

## ⚙️ Configuration

### Hyperparameters

Default hyperparameters can be modified in `hyperparams.json` or passed as command-line arguments:

- `learning_rate`: Learning rate for optimizer (default: 3e-5)
- `batch_size`: Batch size per GPU (default: 4)
- `num_epochs`: Number of training epochs (default: 3)
- `weight_decay`: Weight decay for regularization (default: 0.01)
- `warmup_steps`: Learning rate warmup steps (default: 500)
- `gradient_accumulation_steps`: Steps to accumulate gradients (default: 4)
- `fp16`: Enable mixed precision training (flag)

### Memory Optimization

For GPUs with limited VRAM (6GB), the project uses:
- **Mixed Precision (FP16)**: Reduces memory usage by ~50%
- **Gradient Checkpointing**: Trades computation for memory
- **Gradient Accumulation**: Simulates larger batch sizes

## 🔧 Troubleshooting

### CUDA Out of Memory
- Reduce `batch_size` (try 2 or 1)
- Increase `gradient_accumulation_steps`
- Ensure `--fp16` flag is used

### GPU Not Detected
```bash
# Check CUDA installation
nvidia-smi

# Verify PyTorch CUDA support
python -c "import torch; print(torch.cuda.is_available())"
```

### Dependencies Installation Issues
```bash
# Upgrade pip
pip install --upgrade pip

# Install with no cache
pip install --no-cache-dir -r requirements.txt
```
